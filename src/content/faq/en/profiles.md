---
question: What are the available profiles?
category: Using Zonemaster
---

A profile in Zonemaster is a configuration file that defines a specific set of parameters and options used by the tool.
Specifically, there are custom "preset" profiles that run a subset of all test cases, tailored to a specific use case.
For more information on what each available preset profile does, see the [preset profiles](https://doc.zonemaster.net/latest/configuration/profiles.html#preset-profiles) documentation.
